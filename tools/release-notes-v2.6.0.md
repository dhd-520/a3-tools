# A3Tools v2.6.0

📅 发布日期:2026-09-18

---

## 🎉 新增功能

### 【内测】Root 模式下新增账套导出功能
- 在 Root 模式下,支持把当前账套一键导出(格式兼容原导入)
- 方便备份 / 跨设备迁移 / 团队共享
- ⚠️ 当前为开发内测功能,数据量大时可能有性能波动,建议小账套先试

### 【内测】内置查询工具优化
- SQL 编辑器 IntelliSense 大幅优化:不再因列数过多(200+ 列)漏掉 TOP* 等靠后列名
- 一键格式化 SQL(对齐关键字、统一大小写风格)
- 智能感知异步化不再卡 UI
- 拖选单词吸附问题修复

## ✨ 其他改进

- 模型 / 存储 / UI 全套(CRUD + 扫描)

- 气泡布局重写:自适应宽度 + 自动滚底 + 滚轮转发

## 🐛 问题修复

- IntelliSense: `Take(50)` 把 TOP* 列砍掉导致弹窗不提示(200+ 列宽表受影响)
- 知识库: 8 个工具栏按钮 Click 事件补接
- SQL 编辑器: 拖选单词吸附 / AutoWordSelection 强制
- 主页工具栏按钮宽度不一致
