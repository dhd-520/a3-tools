# v2.2.0 发布说明

## 重点：内置 SQL 查询工具 🎉

陛下从 2026-03 起就在 A3Tools 里集成轻量级 SQL 查询器，v2.2.0 把它作为**内置工具**正式落地（替代 SSMS 日常使用）：

### 核心能力
- **多 Tab 查询** —— 自绘 × 关闭按钮、中键关闭、右键菜单（关闭当前/关闭其他/重命名）
- **对象资源管理器** —— 树状浏览表/视图/函数/存储过程/触发器；右键【复制对象名/复制完整路径/打开脚本】
- **IntelliSense 智能提示** —— 上下文推断 + 50ms 节流；EXEC 后空格、SELECT * 后未输表名都能弹；候选列出来后 Ctrl+滚轮调整字号
- **SQL 高亮** —— 关键字/字符串/数字/注释分色，闪烁冻结重绘 + 滚动位置保留
- **GO 批处理分割** —— 仿 SSMS 把脚本按 GO 拆批执行，单批失败不中断
- **Ctrl+F 查找 / Ctrl+H 替换** —— 上一个/下一个、区分大小写、全部替换
- **多屏位置记忆** —— 记住上次所在屏幕（DeviceName.HashCode），副屏拔走后回退主屏中心
- **多库切换** —— 顶栏下拉 + 异步加载数据库列表

### 工具箱调用方式
账套右键 → **SQL 查询** → 打开 SQL 查询窗

## 详细变更

### 新增
- `SqlEditor`（继承 RichTextBox + SQL 高亮 + IntelliSense 拦截）
- `IntelliSensePopup`（仿 SSMS 弹框，Opacity + TopMost 不抢焦点）
- `LineNumberPanel`（自绘行号 + 当前行高亮 + 跟随字号缩放）
- `ObjectExplorerForm`（树状资源管理器 + 右键菜单）
- `SearchReplaceDialog`（查找替换）
- `SqlIntelliSenseProvider`（关键词/上下文推断/对象缓存）
- `SqlObjectSchemaCache`（库对象元数据异步缓存）
- `SqlQueryForm` / `SqlQueryTabPage`（多 Tab 主窗 + 子页）
- `SqlScriptLoader`（CREATE/ALTER 脚本加载）
- `SettingsStore`（统一设置读写）

### 优化
- 字体默认 11pt → **12pt**；状态栏实时显示当前字号
- 联想框行高 22 → 24（更宽松）
- 联想框定位对准当前光标 X
- 联想框：光标移到别处自动关闭
- Ctrl+滚轮调字号（已可用）
- AutoLayout 高 Dpi 友好
- Highlight() 全量重算 + 滚动条位置保留
- 选中状态精确保存/恢复（selStart/selLen/selColor）

### 修复
- 回车只能输入一次（重写 HandleEnterWithIndent + SuppressKeyPress 顺序）
- 高亮后滚动条跳回顶部（保存 vScroll/hScroll + 恢复）
- 选中状态紊乱（Highlight 多次 Select 干扰）
- tools.json 不支持 // 注释（StripJsonLineComments 预处理字符串外注释）
- 对象资源管理器无法直接操作（右键菜单）
- 主副屏位置不记忆（DeviceName.HashCode 匹配）
- 副屏拔走后位置错位（找不到屏 → 回退主屏中心）

### 工具箱
- 默认带 10 个内置工具（跨库复制系列 + SQL 查询 + 后台/前台搜索）
- tools.json 支持 // 单行注释（基于字符串状态机）
- 注释工具不影响其他工具加载
