# 2026-07-08 v2.3.8 修复（终版）

## 目标
解决 v2.3.9 / v2.3.10 的"找不到路径"问题，陛下要求版本号回到 v2.3.8（旧的 v2.3.8 release 替换 zip）

## 改动（UpdateService.cs）

### 1. bat 详细日志（满足陛下"写清楚日志"要求）
每一步都 echo 到 `_update.log`，包括：
- batPath、cwd、currentExe、zipPath、tempExtract
- STEP 1: unzipping
- STEP 2: src（列出顶层目录内容）
- STEP 3: xcopy 进度 + errorlevel
- STEP 4: 验证 A3Tools.exe 是否被覆盖
- STEP 5: start 新版本

### 2. Plan B：bat 第一行 `cd /d %~dp0`
**核心修复**：不依赖 C# 传的 `WorkingDirectory`，bat 启动时强制切到自己的目录。
无论 C# 传什么都对。

### 3. bat UTF-8 BOM 编码
之前用 `System.Text.Encoding.Default`（中文 Windows = GBK）。改成 `new UTF8Encoding(true)`：
- 文件带 BOM
- `chcp 65001` 才能正确解析中文路径
- 配合 bat 内的 `setlocal` 隔离环境变量

### 4. 保持 v2.3.10 已有改动
`Environment.ProcessPath ?? MainModule.FileName` 已经在 v2.3.10 改过（保留）。

## 关键参数

### 编码
- bat 内容：用 `new System.Text.UTF8Encoding(true)`（UTF-8 BOM）
- 日志输出：cmd `>> {logPath} 2>&1`

### 文件位置
- bat: `{currentDir}\_update.bat`
- log: `{currentDir}\_update.log`（追加模式，每次 update 追加新一段 + 分隔线）

### 启动方式
```csharp
var psi = new ProcessStartInfo
{
    FileName = "cmd.exe",
    Arguments = $"/c start \"\" /b \"{batPath}\"",
    UseShellExecute = true,    // 走 cmd detached
    CreateNoWindow = true,
    WorkingDirectory = currentDir  // 兜底（bat 自己 cd /d %~dp0 自救）
};
```
