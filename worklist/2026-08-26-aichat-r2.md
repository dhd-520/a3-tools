## 关键代码改动

### AiChatForm.cs - BtnSend_Click 新流程
```
1. 发用户消息 → 加进消息列表
2. SendWithToolsAsync(provider, messages, toolCallLog, onToolExecuted)
   ├─ 第一次请求带 tools schema
   ├─ AI 返回 tool_calls → 执行每个 Action（onToolExecuted 回调显示中间状态）
   ├─ tool 结果塞回历史
   ├─ 第二次请求：AI 组织最终回复
   └─ 跳出循环（最多 5 圈防无限循环）
3. StreamDisplayAsync 打字机显示最终文本
4. 保存到 store
```

### 打字机速度
- 中文字符：12ms / 字
- ASCII 字符：6ms / 字
- 用户可按"取消"中断（_cts.Cancel）

## 已知限制
- **打字机只在 Label 上**（简化版），如果 AI 输出长代码块可能渲染慢（因为每字都重渲染 markdown）
- **Function Calling 多轮最多 5 圈**，超出会强行结束（防止 AI 死循环）
- **Action 不能写文件 / 杀进程**（安全考虑），如需写文件 R3 再加
- **Markdown 实时渲染**：流式过程中每字都过 Markdig，**长文本 + 慢机器**可能有轻微卡顿；R3 可考虑优化（每 N 字才渲染一次）
