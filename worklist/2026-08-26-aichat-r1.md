# 2026-08-26 AI 助力 R1

## 状态

## 目标
A3Tools 加 AI 客服（答疑 + 对话历史），第一阶段只做工具使用/配置解答，先不做操作层（Function Calling）和偏好自动提取。

## 陛下拍板
- 形态：菜单入口（**帮助** 下加「AI 助力」+「AI 助力设置」）
- 后端：OpenAI 兼容协议，7 家预设厂商 + 自定义
- 能力：答疑 + 对话历史（暂不做操作、不做偏好自动提取）
- 知识库：独立 `Resources/A3ToolsKnowledge.md`，运行时读取（改知识不用重编）
- 默认存储：Local（AES 加密本地）

## 手动测试清单
1. **打开 AI 助力窗口**
   - [ ] 菜单「帮助 → AI 助力」能弹出窗口
   - [ ] 窗口标题显示「AI 助力 - A3Tools 智能助手」
   - [ ] 关闭后再点能重新打开

2. **打开 AI 助力设置**
   - [ ] 菜单「帮助 → AI 助力设置」弹出设置窗
   - [ ] 左侧厂商列表为空（首次）
   - [ ] 点「� 一键添加预设厂商」→ 弹出预设选择窗
   - [ ] 选 OpenAI → 自动填入默认 URL 和模型
   - [ ] 填 ApiKey → 点「应用到选中厂商」
   - [ ] 点「保存」→ 不报错

3. **聊天测试**
   - [ ] 回到聊天窗口，顶部下拉框能看到刚加的厂商
   - [ ] 切换厂商 → 顶部状态条更新
   - [ ] 输入「A3Tools 怎么添加账套？」按 Enter
   - [ ] 看到 AI 气泡回复（带 Markdown 渲染）
   - [ ] 关掉窗口再打开，左侧会话列表能看到历史

4. **加密验证**
   - [ ] 打开 `DATA/ai_chat_config.json`，ApiKey 应该是密文（Base64-like）
   - [ ] 打开 `DATA/ai_chat/sessions.json`，对话内容应该是密文

5. **存储策略切换**
   - [ ] 设置 → 存储策略切到「仅内存」→ 保存
   - [ ] 发一条消息 → 关程序 → 重开 → 会话没了（符合预期）
   - [ ] 切回「本地加密存储」→ 会话恢复

## 已知限制
- 暂不支持流式输出（等 AI 整个回复完一次性显示）
- 暂不支持图片 / 文件上传
- Markdown 渲染是简化版（剥 HTML 标签 → Label），不显示粗体 / 代码块样式
- 暂不支持 Function Calling（操作层留 R2）
- 暂不支持偏好自动提取（留 R2 或 R3）
