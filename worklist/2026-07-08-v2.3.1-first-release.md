## 遇到的问题

### 1. PowerShell 嵌套 `$env:` 赋值失效
`powershell -NoProfile -Command "$env:GITEE_TOKEN='...'; & script.ps1"` 在 PS 5.1 中：
- 单引号字符串值在嵌套 -Command 里可能没正确传到子进程
- 子进程跑脚本时 `$env:GITEE_TOKEN` 是空 → "Skipping Gitee"

**修法**：用 `-File script.ps1` + 外层 shell 设 env var，或者直接 `-Command "块{ ... }"` 大括号语法

### 2. PS 5.1 Invoke-RestMethod 不支持 -Form
报 "找不到与参数名称 Form 匹配的参数" — 这版本 Invoke-RestMethod 没 -Form。

**修法**：用 `System.Net.Http.HttpClient` + `MultipartFormDataContent` 手写 multipart
```powershell
Add-Type -AssemblyName System.Net.Http
$content = New-Object System.Net.Http.MultipartFormDataContent
$byteContent = New-Object System.Net.Http.ByteArrayContent -ArgumentList @(,$fileBytes)
$byteContent.Headers.ContentType = [System.Net.Http.Headers.MediaTypeHeaderValue]::Parse("application/zip")
$content.Add($byteContent, "file", $fileName)
$client = New-Object System.Net.Http.Httpclient
$response = $client.PostAsync($url, $content).GetAwaiter().GetResult()
```

### 3. gh CLI 失败被 catch 吞掉
脚本里 `& gh release create ... | Out-Null` 错误被 try-catch 吞了，$githubReleaseUrl 还赋了假 URL，导致显示 "Release done" 但实际 GitHub release 根本不存在。

**修法**：
- 加 GITHUB_TOKEN 检测（不要依赖未 auth 的 gh CLI）
- 失败时把异常信息 $_.Exception.Message 输出，不要完全吞
- 或者 `$githubReleaseUrl` 只在真正成功时赋值

### 4. tag 推到空仓库 "成功" 但 release 失败
`git push A3ToolsRelease v2.3.1` 推到空仓库 → OK
但 Gitee API 创建 release 失败 "创建标签失败：v2.3.1" → 因为 Gitee release 是基于已有 tag 关联的，**没 tag 不能建 release**。

**修法**：先 push tag，再调 API（这个现在流程对）
